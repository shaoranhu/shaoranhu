# Shaoran Hu

**Computer Vision · Object Detection · Human Pose Estimation**

I build and evaluate computer vision models, with a focus on people and laboratory apparatus. I'm interested in how model design, data, and evaluation affect performance in real scenes.

## Projects

### Dual-Head YOLO

A YOLO11m-based framework with shared features and separate detection heads for people and laboratory apparatus.

**Research question:** When does sharing features help both tasks, and when does it hurt?

### Human Pose Estimation Benchmarks

Comparing pretrained pose models on COCO to study the trade-offs between accuracy, model size, and inference latency.

## How I work

I document experimental settings, evaluation protocols, and failure cases to make results easier to inspect and reproduce.
